# The Fujoshi Guide to Web Development — website

This is the source for [fujoweb.dev](https://fujoweb.dev), the website for *The Fujoshi Guide to Web Development*: a series of instructional zines about coding by [FujoCoded LLC](https://fujocoded.com), featuring gijinka (anthropomorphizations) of programming languages and concepts. Volume 0 (Git & GitHub) was funded on Kickstarter and Issue 1 has been digitally released to backers.

Looking for the guides themselves? Free companion guides live at [learn.fujoweb.dev](https://learn.fujoweb.dev).

## Development

Built with [Astro](https://astro.build). To run locally:

```sh
npm install
npm run dev
```
